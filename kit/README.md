# ともはね連結キット（ゲームを作っている人へ）

インディーズのゲーム会社や、個人でゲームを作っている人が、推し活SNS「ともはね」のゲーム一覧にゲームを出して、「ともはねでログイン」でつなぐためのキットです。

- `tomohane-link.js`：つなぐ部品（Node 20 から・外部パッケージなし）
- `example-server.js`：いちばん小さな見本のゲーム

## つなぐまでの流れ

1. **ともはねに登録**して（大人・18歳から）、ゲーム一覧のページ（`/games.html`）の「ゲームを作っている人へ」から申しこむ
   - ゲームのID（半角の英小文字・数字・-）、名前、作った人・会社、アドレス、説明、タグ、遊べる年齢（ゲームの内容で選ぶ）
2. 申しこむと **合言葉（`tg_…`）が1回だけ** 出る。サーバーの環境変数などに保存する（コードやリポジトリに書かない）
3. **運営が見て**、一覧に出す（それまでは つなぐ API も使えない）
4. あなたのゲームのサーバーに `/auth/callback` を作って、`redeem(ticket)` で通行証を確かめる
5. 遊んだあとに `report(playerId, { plays, best })` で数だけ知らせる

```
ともはね「遊ぶ」 → /api/link/x/<ID>/start
  → あなたのゲーム /auth/callback?ticket=…（1分・1回だけ）
  → あなたのサーバー → ともはね /api/link/x/<ID>/ticket/<通行証>（X-Link-Secret）
  ← { gameId, name, ageGroup }
あなたのサーバー → ともはね /api/link/x/<ID>/results { gameId, plays, best }
```

## 見本を動かす

```
TOMOHANE_URL=http://localhost:3000 TOMOHANE_GAME_ID=my-game TOMOHANE_SECRET=tg_... node example-server.js
```

## 約束（ともはね の方針）

- **来るのは「ゲーム用の番号・表示名・年齢の区分」だけ。** 本当の ID・パスワード・生年月日は来ない。番号はゲームごとにちがう
- **送れるのは数だけ**（遊んだ回数・いちばんの記録）。文章や写真は送れない
- **広告・課金のあるゲームは置けない。** ともはね のゲームセンターには、広告も課金もないゲームだけを並べる（年齢にかかわらず）
- **遊べる年齢は、ゲームの内容で分ける。** だれでも／中高生から（たたかい・少しこわい表現）／大人だけ。運営も中身を見て決める
- 遊べる年齢に合わない人は、ともはね側で「遊ぶ」が使えない
- 合言葉をなくしたら、新しいIDで申しこみ直す（β版）
