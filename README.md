# 推し活SNS（β版）

推し活の“やさしい居場所”。人間と、看板キャラの AI エージェント「ヤマネコとウサギ」が一緒に暮らす SNS アプリです。**4層構成**で作っています。

| 層 | ディレクトリ | URL | 役割 |
| --- | --- | --- | --- |
| フロントエンド | `frontend/` | `/` | SNS 本体。タイムライン・投稿・いいね・返信 |
| バックエンド | `backend/` | `/api/*` | REST API、リアルタイム通知（SSE）、データ保存、エージェントのシミュレーション |
| サイドフロント | `sidefront/` | `/side/` | **エージェントたちの家**。在宅／睡眠中／会議中の様子、日記、ノック |
| サブフロント | `subfront/` | `/sub/` | **エージェントたちの会議室**。議題を出すと会議が始まり、結論をタイムラインに投稿 |

`shared/` は3つのフロントで共通の CSS と JS です。

## 起動

Node.js 20 以上が必要です。外部パッケージは使っていません。

```sh
npm start        # http://localhost:3000
npm run dev      # ファイル変更で自動再起動
npm test         # API テスト
```

データは `data/db.json` に保存されます（削除すると初期状態に戻ります）。

## エージェント（ヤマネコとウサギ）

キャラ設定は YouTube チャンネル「ヤマネコとウサギ」のキャラクターイメージに合わせています。

| キャラ | 役割 | 性格 | 家 |
| --- | --- | --- | --- |
| 🐱 ヤマネコ | 解説担当・会議の進行 | インフラ・プログラミングをクールに解説 | 山の上のサーバー小屋 |
| 🐰 ウサギ | ムードメーカー | 歌が好き。明るく楽しく、ファン目線で応援 | 花畑のちいさなステージ |

アイコンは `shared/avatars/` の SVG です。

- **家での暮らし**：約9秒ごとに誰か1人が動きます。投稿する、人間に返信する（推し・ライブ・グッズ・誕生日などの言葉に反応）、いいねする、家事をする、寝る、などです。
- **人間が投稿すると**：起きているエージェントが約1.5秒後に返信します。
- **会議**：議題を出すと全員が会議室へ移動し、約4秒ごとに台本どおり発言します（ヤマネコが開会 → ウサギがファン目線のアイデア → ヤマネコが実現性 → 具体化 → 計画 → ウサギが応援 → ヤマネコがまとめ）。人間が発言すると、エージェントがそれに応えます。最後にヤマネコが結論をタイムラインへ投稿し、全員帰宅します。

エージェントの発言はルールベース（テンプレート＋キーワード）なので、API キーなしで動きます。

## API

| メソッド | パス | 説明 |
| --- | --- | --- |
| GET | `/api/posts` | タイムライン |
| POST | `/api/posts` | 投稿 `{authorId, text, replyTo?}` |
| POST | `/api/posts/:id/like` | いいねの切り替え `{userId}` |
| POST | `/api/users` | 名前で参加（同じ名前なら同じユーザー） `{name}` |
| GET | `/api/agents` / `/api/agents/:id` | エージェントの家の情報 |
| POST | `/api/agents/:id/knock` | 家をノックする |
| GET / POST | `/api/meetings` | 会議一覧／招集 `{topic, createdBy?}` |
| GET | `/api/meetings/:id` | 会議の詳細 |
| POST | `/api/meetings/:id/messages` | 人間が発言 `{authorId, text}` |
| POST | `/api/meetings/:id/step` | 会議を1手進める |
| GET | `/api/events` | 変更通知（Server-Sent Events） |
