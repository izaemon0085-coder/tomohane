# ともはね（β版）

推し活SNS「ともはね」。

推し活の“やさしい居場所”。人間と、看板キャラの AI エージェント「ヤマネコとウサギ」が一緒に暮らす SNS アプリです。**4層構成**で作っています。

| 層 | ディレクトリ | URL | 役割 |
| --- | --- | --- | --- |
| フロントエンド | `frontend/` | `/` `/plaza.html` `/cafe.html` `/games.html` `/oshi.html` | SNS 本体。**町の地図**（トップ）→ **広場**（チャット風のタイムライン・いいね・返信）／**カフェ**（テーブルごとのタイムライン）／**ゲームセンター**／**わたしの推し**（推しダッシュボード） |
| バックエンド | `backend/` | `/api/*` | REST API、リアルタイム通知（SSE）、データ保存、エージェントのシミュレーション |
| サイドフロント | `sidefront/` | `/side/` | **エージェントたちの家**。在宅／睡眠中／会議中の様子、日記、ノック |
| サブフロント | `subfront/` | `/sub/` | **エージェントたちの会議室**。議題を出すと会議が始まり、結論をタイムラインに投稿 |

`shared/` は3つのフロントで共通の CSS と JS です。`open/` は手紙キットの受け取りページです（QR から開く。登録なしで見られる）。

4つの層の役割と、中の仕組みのくわしい説明は [docs/architecture.md](docs/architecture.md) にあります。

## 起動

Node.js 20 以上が必要です。外部パッケージは使っていません。

```sh
npm start        # http://localhost:3000
npm run dev      # ファイル変更で自動再起動
npm test         # API テスト
```

データは `data/db.json` に保存されます（削除すると初期状態に戻ります）。

## エージェント（キャラクターたち）

ヤマネコとウサギは YouTube チャンネル「ヤマネコとウサギ」のキャラクターイメージに合わせています。フクロウとシバは、ともはねのコンセプト「悪口から守る・一人にしない」から生まれた仲間です。

| キャラ | 役割 | 性格・口ぐせ | 家 |
| --- | --- | --- | --- |
| 🐱 ヤマネコ | 解説担当・会議の進行 | インフラ・プログラミングをクールに解説（「〜だ」） | 山の上のサーバー小屋 |
| 🐰 ウサギ | ムードメーカー | 歌が好き。明るく楽しく、ファン目線で応援（「〜だよ ♪」） | 花畑のちいさなステージ |
| 🦉 フクロウ | 見守り番 | 夜もねむらない。トゲのある言葉にやさしく注意する（「ほう」「〜ですぞ」） | 森の見張り台 |
| 🐕 シバ | 寄り添い役 | はじめての人に一番に挨拶し、さみしい人に駆けつける（「〜っす」） | 広場のとなりの赤い屋根の家 |

| 🚗 クルマ | 車のエージェント | ガレージで暮らす。ひみつの役目の準備中（「ブルルン」「プップー！」） | 家のガレージ |

| 🐾 モグ | 回線番 | 会議室の金庫に住むモグラ。Wi-Fi とローカル回線を見張って自動で切り替える（「〜モグ」） | 会議室の金庫 |

| 🦝 タヌキ | カフェのマスター | のんびり屋。あいさつと、推しのテーブルを開くかどうかを決める（「まあ、ゆっくりしていきなよ」） | ☕ カフェ |
| 🐧 ペンギン | カフェの店員さん | きちょうめん。テーブルの準備、似た推しの名前をそろえる、はじめての人の案内 | ☕ カフェ |
| 🦊 キツネ | ゲームセンターの店長 | いたずら好きで負けずぎらい（「もう一回！」）。閉店の時間はきっちり守らせる | 🎮 ゲームセンター |
| 🐸 カエル | ゲームセンターの盛り上げ役 | 「ゲロゲロ！ いらっしゃーい！」。新しい台の紹介とおすすめ | 🎮 ゲームセンター |

クルマはガレージで暮らすだけで、投稿・返事・会議・遊び場には出てきません。町の地図には、準備中のひみつ機能の「？？？？」の看板が2つあります（右下はクルマのひみつの役目、左下はあとで作る別のアプリ。新しいエージェントも来る予定）。

**だれが返事をするか**：トゲのある言葉 → フクロウ（寝ていても起きる）／その人のはじめての投稿・さみしい投稿 → シバ／それ以外 → 起きているだれか。

**送る前のチェック**（`shared/precheck.js`）：広場で「送る」を押すと、キャラたちが文面にひとこと声をかけます。何もなければ何も出ません。声をかけるのは1回に2人まで。決めるのは本人で、「このまま送る／直す／やめる」から選びます。

| キャラ | 出すもの | 例 |
| --- | --- | --- |
| 🦉 フクロウ | 警告 | トゲのある言葉、電話番号や住所、人の名前や住んでいる場所の書きこみ（さらし） |
| 🐱 ヤマネコ | 質問 | 「その話、どこで知った？」（うわさ・拡散希望）、「それは事実か、感想か？」（決めつけ） |
| 🐰 ウサギ | 意見 | 「最悪」→「今日のは残念だった」のような言いかえ |
| 🐕 シバ | 寄り添い | 怒りやくやしさを受け止めて、「少し時間をおいてから送るのもアリっす」 |

- **はっきりした犯罪は送れない**：闇バイトの募集、人をおびやかす言葉（殺害予告など）、チケットの不正転売、「必ずもうかる」詐欺。画面を通さずに送られても、サーバーが同じ判定で止める（広場の投稿と会議室の発言）
- 推し活の言い方（「推しね」「〜ばかり」「尊くて死ねる」「殺す気か」など）は、トゲあつかいしない
- β版は決まった言葉のパターンで見分ける。文面はともはねの外に出さない。あとで AI（言葉の意味が分かるもの）に入れかえる予定

アイコンは `shared/avatars/` の SVG です。

- **家での暮らし**：約9秒ごとに誰か1人が動きます。投稿する、人間に返信する（推し・ライブ・グッズ・誕生日などの言葉に反応）、いいねする、家事をする、寝る、などです。
- **人間が投稿すると**：起きているエージェントが約1.5秒後に返信します。
- **会議**：議題を出すと全員が会議室へ移動し、約4秒ごとに台本どおり発言します（ヤマネコが開会 → ウサギがファン目線 → シバが寄り添い目線 → ヤマネコが実現性 → フクロウが安全面 → 具体化 → 計画 → シバとウサギが応援 → ヤマネコがまとめ）。人間が発言すると、エージェントがそれに応えます。最後にヤマネコが結論をタイムラインへ投稿し、全員帰宅します。

### 🍚 やりくり献立との連結（デモ）

同じパソコンにある「やりくり献立」（Python / Streamlit）とつながります（`backend/kondate.js`）。

- やりくり献立で献立を作ると、やりくり献立が `kondate_latest.json` に最新の献立を保存する
- ともはねはそのファイルを**読むだけ**（20秒ごと）。新しい献立を見つけると、ウサギが広場で「きょうの晩ごはん」を紹介し、ヤマネコが食費の合計を、シバが応援をひとこと返す（同じ献立は1回だけ）
- 町の地図の「🍚 やりくり献立」のお店に、今夜の晩ごはんが出る。押すとやりくり献立（`http://localhost:8501/`）が開く
- やりくり献立のフォルダとアドレスは、環境変数 `YARIKURI_DIR` / `YARIKURI_URL` で変えられる

### ✉️ 手紙キット（β版）

紙の手紙に QR コードをそえて、**声と顔のビデオレター**を届けます（町の地図の 📮 ポスト、またはヘッダーの「✉️ 手紙」から）。

- **つくる**（`/letter.html`）：宛名 → 便箋と字体（便箋はβ版はクリーム1種類。ふちは推しカラー。字体は、はじめはきせかえで選んでいるもの）→ ビデオ（3分・200MB まで）→ QR コード
- **保存する**：「便箋を画像で保存」（A4・いちばん下に QR）か「QR だけ保存」。**印刷はセブンイレブンのアプリで**行う（アプリに印刷機能はない）
- **受け取る**（`/open/#<合言葉>`）：QR を読むと封筒が出て、タップするとひらいてビデオが流れる。**ともはねの登録はいらない**。文字は送った人が選んだ字体になる（てがき風は線が細いので少し大きく出す）
- **とどいた**：受け取った人が封筒をひらくと、作った人の「つくった手紙」に「💌 とどきました」と出て、シバが知らせる（作った人だけ）
- **ともはねのほかのユーザーには送れない**。手紙は広場にも出ない。届け方は紙の手紙＋QR だけ
- **合言葉**：作ったときにだけ返す合言葉が、作った端末のブラウザに保存される。一覧・削除はこの合言葉がないとできない（β版はパスワードのログインがないため）。サーバーには合言葉のハッシュだけを残す
- **キャラ**：ウサギが案内、ヤマネコがビデオの長さと大きさを確認、フクロウが電話番号や住所らしき文字に注意、シバが「できた」「とどいた」を知らせる
- **QR コード**は外部パッケージなしの自作（`shared/qrcode.js`。誤り訂正レベル M・型番 1〜10）。インターネットがなくても作れる
- **β版はまだ家の Wi-Fi の中だけ**：このパソコン（localhost）で作ると、QR には同じ Wi-Fi のアドレスが入る。遠くの家族に届けるのはインターネット版（AWS）から
- 動画は `data/letters/videos/` に保存される。iPhone の動画（mov）は、パソコンのブラウザでは再生できないことがある。「ためしにひらく」をスマホで確かめる

### ♿ こことも（移動サポートのアプリ）との連結

旅や、障害のある人の移動を助けるアプリ「こことも」（別のリポジトリ。ふだんは `http://localhost:3100/`）とつながります（`backend/kokotomo.js`）。

- 「わたしの推し」に次のライブ会場を登録すると、その会場のバリアフリーメモ（エレベーター・多目的トイレ・車いす席など）の要点が出て、ヤマネコがひとこと案内する
- ともはねから こことも へ送るのは **会場の名前だけ**。こことも の「おたすけカード」や位置情報は、ともはねには来ない
- こことも が起動していないときは「こことも で調べる」リンクだけを出す（ともはねは止まらない）
- こことも のアドレスは環境変数 `KOKOTOMO_URL` で変えられる

### ✊ ともじゃん（じゃんけん）との連結

ゲームは別のアプリ「ともじゃん」（`tomojan`、ふだんは `http://localhost:3300/`）で、ともはねとつながります（`backend/gamelink.js`）。

- 🎮 ゲームセンターの台から開く（前は地図のシバの家の上にあった入口を、ゲームセンターにまとめた）
- 押すと「ともはねでログイン」：ともはねが1分だけ・1回だけ使える通行証を出し、ゲームのサーバーが合言葉（`LINK_SECRET`）つきで確かめる
- ゲームに渡すのは、ゲーム用の番号（ともはねの ID そのものではない）・表示名・年齢の区分だけ。ゲームから受けとるのは勝ち数と参加回数だけ（アカウントの画面に出る）
- 環境変数：`GAME_URL`（ゲームのアドレス）、`LINK_SECRET`（ゲームと同じ値。本番では必ず設定）

### 👻 ゴーストエージェント（昨日の自分と競う）との連結

別のアプリ「ゴーストエージェント」（`ghost-agent`、ふだんは `http://localhost:3500/`）とつながります。ともじゃんと同じ「ともはねでログイン」のしくみで、アプリ用の番号はアプリごとにちがいます（ともじゃんとゴーストの番号を見比べても、同じ人だと分からない）。

- 町の地図の「👻🏃 グラウンド」から開く
- ゴーストから受けとるのは「自己ベストを更新した回数」と「続けた日数」だけ（アカウント画面に出る）。ラップの記録そのものは来ない
- 自己ベストを更新したら、ゴーストの「ともはねの広場で知らせる」で、広場の投稿欄に**下書き**が入る（`/plaza.html?draft=…`）。送るかどうかは本人が決める
- 環境変数：`GHOST_URL`（ゴーストのアドレス）、`LINK_SECRET`（ゴーストと同じ値）

### 🏪 みせとも（お店のアプリ）との連結

別のアプリ「みせとも」（`misetomo`、ふだんは `http://localhost:3600/`）とつながります。今あるレジの表（CSV）とつないで、タグシールで在庫と防犯（商品を追う・人は追わない）。

- 町の地図では、名前を出さずに3つ目の「？？？？」（右の上）。押すと「ともはねでログイン」で開く
- つながるのはログインだけ（番号はアプリごとにちがう）。**お店の在庫やお客さんのことは、ともはねに来ない**
- 環境変数：`MISETOMO_URL`（みせとものアドレス）、`LINK_SECRET`（みせともと同じ値）

### 🛰️ そらとも（人工衛星の運用ゲーム）との連結

別のアプリ「そらとも」（`soratomo`、ふだんは `http://localhost:3800/`）を、**ともはねのゲーム**としてつなぎます。

- 🎮 ゲームセンターの台から開く（「ともはねでログイン」、番号はアプリごとにちがう）

- 環境変数：`SORATOMO_URL`（そらとものアドレス）、`LINK_SECRET`（そらともと同じ値）

### 🤖 ころとも（ラジコンの小さなロボット）との連結

別のアプリ「ころとも」（`korotomo`、ふだんは `http://localhost:3700/`）を、**ともはねのゲーム**としてつなぎます。

- 🎮 ゲームセンターの台から開く（「ともはねでログイン」、番号はアプリごとにちがう）
- 星を3つ集めてゴールするゲーム。ともはねが受けとるのは「ゴールの回数」と「遊んだ回数」だけ（アカウント画面に出る）

### 📶 ローカル回線（オフライン対応・同じ Wi-Fi で使う）

ヘッダーの 📶 から、つながりのようすを見られます（`shared/network.js` / `outbox.js` / `frontend/sw.js`）。

- **オフラインでも見られる**：前に見たタイムライン・家・会議を端末に保存しておき、回線が切れても表示する（Service Worker。`localhost` か https で開いたときだけ動く）
- **送信待ち**：オフラインで投稿すると端末にためて「📮 送信待ち」と表示。つながったら自動で送る（取り消しもできる）
- **同じ Wi-Fi の端末から入れる**：サーバーを起動すると `http://192.168.x.x:3000/` のようなアドレスが表示される。インターネットがなくても、同じ Wi-Fi の端末ならこのアドレスで使える（パネルにも表示・コピー可）
- **キャラの反応**：回線が切れるとフクロウが「投稿はためておきますぞ」、戻るとシバが「つながったっす！」、ためた投稿を送るとシバが報告する
- **回線番のモグ（会議室の金庫）**：15秒ごとに回線を見張り、インターネットにつながれば「📶 Wi-Fi」、インターネットが切れても同じ Wi-Fi の中なら「🏠 ローカル回線」、どちらもだめなら「🔌 この端末だけ」に自動で切り替える。ヘッダーの表示もそれに合わせて変わる。会議室の左下の「🔒 金庫（回線室）」で、切り替え盤と切り替えの記録が見られる（インターネットの確認先は環境変数 `NET_CHECK_HOST` で変えられる）
- 近くの端末どうしで電波をバケツリレーする「メッシュ回線」は準備中

> ⚠️ 家の Wi-Fi（`http://192.168.…`）で使うときは、通信が暗号になっていません。同じ Wi-Fi の中なら、パスワードを盗み見られるおそれがあります。家など信頼できる Wi-Fi だけで使ってください。Windows で「ファイアウォールの許可」が出たら、プライベートネットワークだけ許可してください。

### きせかえ（推し活デザイン）

ヘッダーの「🎨 きせかえ」から、画面を自分の推し活スタイルに変えられます（`shared/customize.js` / `customize.css`）。設定はこのブラウザに保存されます。

> **β版では「推しカラー」と「字体」を変えられます。** もよう・推しマーク・飾り・レイアウトは作ってありますが、正式版まで隠しています（`shared/customize.js` の `BETA_COLOR_ONLY` を `false` にすると全部使えます）。

- **推しカラー**：10色＋好きな色。ボタン・リンク・背景・ふちが推しの色に染まる（明るい色は文字だけ読みやすく暗くする）
- **字体**：ふつう／まるゴシック（Zen Maru Gothic）／てがき風（Klee One）／ぽってり丸（Kiwi Maru）。手紙キットの便箋と受け取りページにも使える。字体のファイルは `shared/fonts/` に置いている（ネットがなくても出る）。字体はユーザーのリクエストなどで、あとから増やす（増やし方は `shared/fonts/README.md`）
- **背景のもよう**：なし／ドット／ストライプ／チェック／ハート／星
- **推しマーク**：💖⭐🎀🌸👑🌙🐾🎤🍀 をロゴの横に。カードにシールとして貼ることもできる
- **飾り**：推しの名前をヘッダーの下に表示／ヘッダーをキラキラにする
- **レイアウト**：サイドの欄の位置（左・右）、画面の幅、カードの形（まる・ふんわり・しかく）、文字の大きさ
- 「はじめの見た目に戻す」でいつでも元どおり
- **キャラたちの意見**：変えるたびに、キャラが性格どおりにひとこと言う（`shared/kisekae-opinions.js`）。ウサギは色や飾りに大はしゃぎ、ヤマネコはレイアウトを冷静に評価、フクロウは目へのやさしさや安全（推しの名前の欄に電話番号などを書くと注意）、シバはとにかくほめる。会議中・お昼寝中のキャラは意見しない。閉じると遊び場のキャラがまとめのひとことを言う

### キャラの遊び場

どの画面でも、下の帯でキャラたちが歩き回って遊んでいます（`shared/playground.js` / `playground.css`）。

- 歩く・休む・ジャンプする。近くにいる仲間と一緒に遊ぶ。歩き方もキャラごとにちがう（ヤマネコはゆらゆら、ウサギはぴょんぴょん、フクロウはふわふわ、シバはちょこちょこ）
- タイムラインに投稿すると、吹き出しでその内容をしゃべる
- クリックすると反応して声を出す
- 寝ているときはその場でお昼寝。会議中は秘密基地にいるので、遊び場からいなくなる
- 右下の「小・中・大・特大」でキャラの大きさを変えられる（スマホでは 0.75 倍。選んだ大きさはブラウザに保存）
- 右下の 🐾 ボタンで隠す／呼ぶ。動きを減らす設定（prefers-reduced-motion）では歩き回らない

### 【仮】読み上げ機能

投稿・ノックの返事・会議の発言についている 🔊 ボタン、または**アイコンをクリック**すると、文章を声で読み上げます（もう一度押すと停止）。キャラ一覧や家の大きいアイコンは自己紹介、会議室の席のアイコンはその人の最新の発言を読みます。ブラウザ標準の Web Speech API を使っているため、声は OS に入っている日本語音声です。ヤマネコは低め、ウサギは高め・はやめ、フクロウはとても低く・ゆっくり、シバは元気に早口で読みます。設定は `shared/speech.js` にあります。将来はキャラ専用の音声に差し替える予定です。

エージェントの発言はルールベース（テンプレート＋キーワード）なので、API キーなしで動きます。

## 🪶 はじめての案内スライド

登録して回復コードを書き留めると、`/welcome.html` で ともはね の使い方を7枚のスライドで案内します（アカウントのページからいつでも見なおせる）。

- **案内役は確率で決まる**：ヤマネコ・ウサギ・フクロウ・シバ（それぞれ最低10%）と、めったに出ない **エンマ大王フクロウ**（1〜5%）
- **確率は毎週月曜日0時（日本時間）に変わる**。週の名前から決まる乱数なので、同じ週ならだれが見ても同じ確率。最後のスライドで今週の確率を見せる（`shared/welcome-guide.js`）
- 説明の文はみんな同じで、案内役のひとことだけが性格どおりに変わる。クルマとモグは持ち場をはなれないので案内しない

## 📰 ともはね新聞

上のメニューの「📰 新聞」（`/news.html`）。**毎週月曜日**に出して、大きな知らせ（コラボ商品が決まったときなど）は**号外**で出します。創刊号は「運営開始のごあいさつ号」です。

- 紙面：題字・号数／一面の見出し／記事（運営・キャラの記者）／キャラのひとこと／座談会／みんなに聞きたいこと（アンケート）／バックナンバー。号外は赤い帯
- **アンケートの結果は数字やグラフで見せない**。キャラたちの座談会で「〜が目立つな」「〜って人もいたっす！」のように、ぼんやり伝える。少ない意見も必ずだれかが拾い、多い順には並べない。答えが5人そろうまでは話さない。正確な数とひとことは運営だけが見られる（サーバーも、運営以外には数を返さない）
- 号ごとに、公式アカウント「**ともはね新聞社**」が広場に**スレッド**を立て、記者のキャラが最初に返事をする。広場の一覧ではスレッドの中の返信をまとめて「💬 スレッドを読む・話す（N件）」と出す
- 町の地図の「📰 新聞社」に、まだ読んでいない号があると「新しい号」、号外なら「号外」の札が付く
- 号は `shared/news.js` の `ISSUES` の先頭に足す。日付が来るまでは出ない（先に書いておける）
- スレッドは半年で倉庫へ、1年でパソコンに圧縮して暗号化 → メモリーカードへ、の予定（まだ作っていない）

### 📮 目安箱（ユーザーの声）

新聞のページのいちばん下（新聞社の前）にあります。記者のキャラが受け取ります（`shared/suggest.js`）。

- テーマ（カフェ・ゲームセンター・キャラ・安全・新聞・そのほか）を選んで、200文字まで・1日3通まで。ログインが必要。送る前のチェックを通る
- 入れると、その日の記者（シバ・ウサギ・ヤマネコ・フクロウが日ごとに交代）がお礼のひとことを返す
- **だれが書いたかは、運営にも見せない**（年齢の区分だけ）。運営は新聞のページの「運営だけ：目安箱に届いた声」で読む
- 運営が「新聞でとりあげる」ときは、**本人と分からないように運営が短くまとめて（要約）、答えを書く**。新聞の「📮 目安箱から」の座談会で、記者が要約を読み、ほかのキャラが運営の答えを伝える（新しい6つ）。書いた本人にだけ「📮 あなたの声がのっています」と出る
- 「片づける」と、新聞からも外れる。退会した人の声は、とりあげていないものは消し、とりあげたものは（だれのものか分からない形で）残す

## 🛡️ 身を守るしくみ（ミュート・ブロック・通報・投稿を消す）

「悪口から守る・一人にしない」ためのしくみです。広場でもカフェでも同じように効きます。

- **ミュートかブロックかを本人が選ぶ**：ミュート＝その人の投稿が自分に見えなくなる／ブロック＝それに加えて、自分の投稿へのその人の返信がほかの人にも見えなくなる。**相手には知らせない**。理由は書いても書かなくてもよく、書いた理由はキャラだけが読む（サーバーも返さない）。理由なしでブロックすると、シバが1回だけ「まちがえてないっすか？」と聞く（押しまちがい・家族がさわった、など）。アカウントのページで一覧・切りかえ・外すができる
- **通報（🚩）**：理由は5つ。軽い（いやな言い方・しつこい）と重い（くり返しのいやがらせ・さらし・犯罪やおどし）。通報した人はだれにも出さない
  - 書いた本人にだけ、キャラが声をかける。軽いものはシバかウサギがやさしく「直す・消す・あやまる」をすすめる。重いものはフクロウが変身して伝える（くり返し→お巡りさん、さらし→弁護士、犯罪・おどし→エンマ大王もどき。本物ではないと書いてある）
  - さらし・犯罪やおどしは、運営が見るまでほかの人に見えなくする。止める・出す・警察に知らせる、を決めるのは運営（人）。運営の一覧はアカウントのページ（通報した人の名前は出さず、人数だけ）
  - あやまりは、通報した人が「読む／読まない」を選ぶ
  - 理由とセリフは `shared/report.js`
- **投稿を消す（🗑）**：自分の投稿だけ。サーバーにも残さない。キャラが明るく「また待ってるよ」。返信がついていたら、返信した人へひとこと（「ありがとう／頑張ります／応援してください」か、自分のことば50字まで。送る前のチェックを通す）を届ける。返信は元の投稿と一緒に見えなくなる（書いた本人は自分のを見られる）。通報のお知らせからも消せる

## ☕ カフェ（テーブルごとのおしゃべり）

町の地図の「☕ カフェ」（`/cafe.html`）。広場は「みんなのおしゃべり」のまま、カフェはテーブルごとに話します。マスターは 🦝 タヌキ、店員さんは 🐧 ペンギン。

- **テーブルは3種類**：フリーテーブル（なんでも）／ジャンル（アイドル・アニメ・ゲーム・歌い手/VTuber・スポーツ・そのほか。`shared/cafe.js`）／推しのテーブル（ジャンルの中）
- **ジャンルはユーザーの声で増やす**：ほしいジャンルをリクエスト（30文字まで・1人3つまで）→ ペンギンが受け取る → 運営がアカウントのページで足す。だれが出したかは運営にも出さない
- **推しのテーブルはキャラが開く**：「わたしの推し」に同じ推し（とジャンル）を登録した人が3人になると、タヌキがテーブルを開く。似た名前（全角半角・かなカナ）はペンギンがそろえる。運営は閉じられる（閉じたテーブルはタヌキが開け直さない）
- 投稿は `/api/posts?table=<テーブルのID>`。カフェの投稿は広場には出ない

## 🎮 ゲームセンター

町の地図の「🎮 ゲームセンター」。地図にばらばらにあったゲームの入口（じゃんけん・ころとも・そらとも）をまとめ、ゲーセン風の台（筐体）にしました。店長は 🦊 キツネ、盛り上げ役は 🐸 カエル。グラウンド（ゴースト）は運動なので地図に残しています。

- **夜は閉まる（日本時間）**：こども（12歳まで）21時・中高生22時・大人24時に閉店、朝6時に開店。画面だけでなく、サーバーの「ともはねでログイン」の入口でも止める（`shared/arcade.js`）
- コインやお金の絵は使わない
- キャラと時間は、あとでユーザーの声でアップデートする

## 🎮 ゲーム一覧

`/games.html`（上のメニューの「🎮 ゲーム」）に、ともはねで遊べるゲームが並びます。もとからある4つ（ともじゃん・ゴーストエージェント・ころとも・そらとも）と、運営が一覧に出したインディーズ・個人のゲームです。ともあい（お金のゲーム）は公開しないので出しません。

- **おすすめ**：ログインした人は、ゲームを「おすすめ」できる（一言は60文字まで。犯罪の文面は送れない）。一覧には、おすすめの数と、推しの名前つきの声（最近の5つ）が出る
- **シバのおすすめ**：一覧の上と、広場で「おすすめのゲームある？」と聞いたときに、シバが答える。選ぶ順番は「同じ推しの人のおすすめ → みんなのおすすめ → 一覧のはじめ」
- **年齢**：遊べる年齢に合わないゲームは出さない。子ども（12歳まで）とログインしていない人には、広告・課金のあるゲームを出さない
- **ゲームを作っている人へ**：`/kit/` のキット（`README.md`・`tomohane-link.js`・`example-server.js`）をダウンロードして「ともはねでログイン」をつなぐ。大人が申しこむと、ゲームごとの合言葉が1回だけ出る（ハッシュだけ保存）。運営が「一覧に出す」と、一覧と連結（`/api/link/x/<ID>/start`・`/ticket/:通行証`・`/results`）が使えるようになる。渡すのは ゲーム用の番号・表示名・年齢の区分だけ、受け取るのは 遊んだ回数・いちばんの記録 の数だけ

## 🔑 ログイン

`/login.html` から、ログイン・はじめる（登録）・パスワードを忘れた、ができます。投稿・いいね・推しページ・手紙・会議の発言は、**ログインしている本人**として扱います（前の「名前だけで入る」は、なりすましができるのでやめました）。

- **登録**：ログインID（半角の英小文字・数字・_）・表示名・パスワード（8文字から）・生年月日。「ともはね の約束」への同意が要る
- **📜 ともはね の約束**（`/terms.html`、利用規約・プライバシー）：運営の信念・運営の誓い・みんなに必ず守ってもらうこと・あずかる情報（何のため・だれが見る・いつ消える）・子どもとおうちの人・見せて／直して／消して・β版について。「おとなむけ／こどもむけ」を切りかえられる（子どもが開くと、はじめから こどもむけ。シバがひらがなで説明）。中身を変えたら `shared/terms.js` の `TERMS_VERSION` を新しくする → いまいる人も、次に開いたときに約束のページへ案内され、もう一度同意する。**β版の下書きなので、本番の前に専門の人に見てもらう**
- **個人情報の問い合わせ**：β版は目安箱の「🔒 個人情報」のテーマで受ける（このテーマだけ、本人か確かめるために運営に名前が分かる。新聞にはのせない）。本番でメールを足す
- **回復コード**：登録したときに8つ出る。パスワードを忘れたら1つ使って新しいパスワードにする（1回だけ使える。使うと、前のログインは全部切れる）。メールを使わないので、家の Wi-Fi だけでも使える
- **年齢の区分**：生年月日から、子ども（12歳まで）・中高生（13〜17歳）・大人（18歳から）。β版は自己申告。マイナンバーカードでの確認は、あとで足す
- **保護者とつなぐ**：アカウントのページで、おうちの人（大人）が「つなぐコード」（30分・1回だけ）を出し、子ども（12歳まで）が自分の画面で入れるとつながる。おうちの人は2人まで。おうちの人に見えるのは、子どもの広場の投稿（最近の5つ）とゲームの数だけ（手紙・推しページ・生年月日は見えない）。つなぐのをやめられるのは、おうちの人だけ
- **管理者**：いちばん最初に登録した人が運営（管理者）になる
- **引っ越し**：前に「名前だけ」で使っていた人は、同じ表示名で登録すると、推しページなどをそのまま引きつげる（最初に登録した人のものになる）
- **退会**：アカウントのページの「退会する」から。パスワードで本人か確かめる。申しこむと、キャラたちが明るく見送る（`shared/leave.js`）
  - **7日たってから消える**：アカウント・投稿・いいね・手紙（QR も開けなくなる）・推しページ・ゲームの記録・おすすめ・アンケートの答え。消したものは倉庫にも入れない。通報した記録は、だれが通報したかだけ消して残す
  - 7日のあいだは、ログインすれば取り消せる。そのあいだ、投稿はほかの人に見えず、新しく投稿もできない
  - 返信をもらっていた投稿があれば、返信した人へ「ひとこと」を届ける（投稿を消すときと同じ3つか、自分のことば）。届くのは本当に消えたときだけ。返信は書いた本人にだけ見えるようになる
  - 子ども（12歳まで）も一人で退会できる。おうちの人とつながっていれば、**シバの日記**でおうちの人に伝わる（アカウントのページ、おうちの人だけに見える）。子どもは7日で入れなくなるが、機種変更などのまちがいに備えて、データは**14日まで**残し、おうちの人が取り消せる。取り消し・旅立ちも日記に書く（友達・先生にも伝える形は、つながるしくみができてから）
  - 運営（管理者）は退会できない（β版には、運営をゆずるしくみがまだない）
  - サーバーは、起動したときと1時間ごとに、7日たった人を消す
- **守るしくみ**：パスワードと回復コードは元にもどせない形（scrypt・SHA-256）で保存／ログインのしるしは JavaScript から読めないクッキー（30日）／5回まちがえると5分待つ／ほかのページからの書きこみは受けつけない／推しページは本人だけが見られる
