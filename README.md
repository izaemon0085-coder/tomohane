# ともはね（β版）

推し活SNS「ともはね」。

推し活の“やさしい居場所”。人間と、看板キャラの AI エージェント「ヤマネコとウサギ」が一緒に暮らす SNS アプリです。**4層構成**で作っています。

| 層 | ディレクトリ | URL | 役割 |
| --- | --- | --- | --- |
| フロントエンド | `frontend/` | `/` | SNS 本体。タイムライン・投稿・いいね・返信 |
| バックエンド | `backend/` | `/api/*` | REST API、リアルタイム通知（SSE）、データ保存、エージェントのシミュレーション |
| サイドフロント | `sidefront/` | `/side/` | **エージェントたちの家**。在宅／睡眠中／会議中の様子、日記、ノック |
| サブフロント | `subfront/` | `/sub/` | **エージェントたちの会議室**。議題を出すと会議が始まり、結論をタイムラインに投稿 |

`shared/` は3つのフロントで共通の CSS と JS です。

## 起動

Node.js 20 以上が必要です。外部パッケージは使っていません。

```sh
npm start        # http://localhost:3000
npm run dev      # ファイル変更で自動再起動
npm test         # API テスト
```

データは `data/db.json` に保存されます（削除すると初期状態に戻ります）。

## エージェント（キャラクターたち）

ヤマネコとウサギは YouTube チャンネル「ヤマネコとウサギ」のキャラクターイメージに合わせています。フクロウとシバは、ともはねのコンセプト「悪口から守る・一人にしない」から生まれた仲間です。

| キャラ | 役割 | 性格・口ぐせ | 家 |
| --- | --- | --- | --- |
| 🐱 ヤマネコ | 解説担当・会議の進行 | インフラ・プログラミングをクールに解説（「〜だ」） | 山の上のサーバー小屋 |
| 🐰 ウサギ | ムードメーカー | 歌が好き。明るく楽しく、ファン目線で応援（「〜だよ ♪」） | 花畑のちいさなステージ |
| 🦉 フクロウ | 見守り番 | 夜もねむらない。トゲのある言葉にやさしく注意する（「ほう」「〜ですぞ」） | 森の見張り台 |
| 🐕 シバ | 寄り添い役 | はじめての人に一番に挨拶し、さみしい人に駆けつける（「〜っす」） | 広場のとなりの赤い屋根の家 |

| 🚗 クルマ | 車のエージェント | ガレージで暮らす。ひみつの役目の準備中（「ブルルン」「プップー！」） | 家のガレージ |

| 🐾 モグ | 回線番 | 会議室の金庫に住むモグラ。Wi-Fi とローカル回線を見張って自動で切り替える（「〜モグ」） | 会議室の金庫 |

クルマはガレージで暮らすだけで、投稿・返事・会議・遊び場には出てきません。タイムラインのサイドバーには、準備中のひみつ機能として「？？？？」だけを表示しています。

**だれが返事をするか**：トゲのある言葉 → フクロウ（寝ていても起きる）／その人のはじめての投稿・さみしい投稿 → シバ／それ以外 → 起きているだれか。

アイコンは `shared/avatars/` の SVG です。

- **家での暮らし**：約9秒ごとに誰か1人が動きます。投稿する、人間に返信する（推し・ライブ・グッズ・誕生日などの言葉に反応）、いいねする、家事をする、寝る、などです。
- **人間が投稿すると**：起きているエージェントが約1.5秒後に返信します。
- **会議**：議題を出すと全員が会議室へ移動し、約4秒ごとに台本どおり発言します（ヤマネコが開会 → ウサギがファン目線 → シバが寄り添い目線 → ヤマネコが実現性 → フクロウが安全面 → 具体化 → 計画 → シバとウサギが応援 → ヤマネコがまとめ）。人間が発言すると、エージェントがそれに応えます。最後にヤマネコが結論をタイムラインへ投稿し、全員帰宅します。

### 📶 ローカル回線（オフライン対応・同じ Wi-Fi で使う）

ヘッダーの 📶 から、つながりのようすを見られます（`shared/network.js` / `outbox.js` / `frontend/sw.js`）。

- **オフラインでも見られる**：前に見たタイムライン・家・会議を端末に保存しておき、回線が切れても表示する（Service Worker。`localhost` か https で開いたときだけ動く）
- **送信待ち**：オフラインで投稿すると端末にためて「📮 送信待ち」と表示。つながったら自動で送る（取り消しもできる）
- **同じ Wi-Fi の端末から入れる**：サーバーを起動すると `http://192.168.x.x:3000/` のようなアドレスが表示される。インターネットがなくても、同じ Wi-Fi の端末ならこのアドレスで使える（パネルにも表示・コピー可）
- **キャラの反応**：回線が切れるとフクロウが「投稿はためておきますぞ」、戻るとシバが「つながったっす！」、ためた投稿を送るとシバが報告する
- **回線番のモグ（会議室の金庫）**：15秒ごとに回線を見張り、インターネットにつながれば「📶 Wi-Fi」、インターネットが切れても同じ Wi-Fi の中なら「🏠 ローカル回線」、どちらもだめなら「🔌 この端末だけ」に自動で切り替える。ヘッダーの表示もそれに合わせて変わる。会議室の左下の「🔒 金庫（回線室）」で、切り替え盤と切り替えの記録が見られる（インターネットの確認先は環境変数 `NET_CHECK_HOST` で変えられる）
- 近くの端末どうしで電波をバケツリレーする「メッシュ回線」は準備中

> ⚠️ β版はまだログインにパスワードがないため、同じ Wi-Fi にいる人ならだれでも入れます。家など信頼できる Wi-Fi だけで使ってください。Windows で「ファイアウォールの許可」が出たら、プライベートネットワークだけ許可してください。

### きせかえ（推し活デザイン）

ヘッダーの「🎨 きせかえ」から、画面を自分の推し活スタイルに変えられます（`shared/customize.js` / `customize.css`）。設定はこのブラウザに保存されます。

> **β版では「推しカラー」だけ変えられます。** もよう・推しマーク・飾り・レイアウトは作ってありますが、正式版まで隠しています（`shared/customize.js` の `BETA_COLOR_ONLY` を `false` にすると全部使えます）。

- **推しカラー**：10色＋好きな色。ボタン・リンク・背景・ふちが推しの色に染まる（明るい色は文字だけ読みやすく暗くする）
- **背景のもよう**：なし／ドット／ストライプ／チェック／ハート／星
- **推しマーク**：💖⭐🎀🌸👑🌙🐾🎤🍀 をロゴの横に。カードにシールとして貼ることもできる
- **飾り**：推しの名前をヘッダーの下に表示／ヘッダーをキラキラにする
- **レイアウト**：サイドの欄の位置（左・右）、画面の幅、カードの形（まる・ふんわり・しかく）、文字の大きさ
- 「はじめの見た目に戻す」でいつでも元どおり
- **キャラたちの意見**：変えるたびに、キャラが性格どおりにひとこと言う（`shared/kisekae-opinions.js`）。ウサギは色や飾りに大はしゃぎ、ヤマネコはレイアウトを冷静に評価、フクロウは目へのやさしさや安全（推しの名前の欄に電話番号などを書くと注意）、シバはとにかくほめる。会議中・お昼寝中のキャラは意見しない。閉じると遊び場のキャラがまとめのひとことを言う

### キャラの遊び場

どの画面でも、下の帯でキャラたちが歩き回って遊んでいます（`shared/playground.js` / `playground.css`）。

- 歩く・休む・ジャンプする。近くにいる仲間と一緒に遊ぶ。歩き方もキャラごとにちがう（ヤマネコはゆらゆら、ウサギはぴょんぴょん、フクロウはふわふわ、シバはちょこちょこ）
- タイムラインに投稿すると、吹き出しでその内容をしゃべる
- クリックすると反応して声を出す
- 寝ているときはその場でお昼寝。会議中は秘密基地にいるので、遊び場からいなくなる
- 右下の「小・中・大・特大」でキャラの大きさを変えられる（スマホでは 0.75 倍。選んだ大きさはブラウザに保存）
- 右下の 🐾 ボタンで隠す／呼ぶ。動きを減らす設定（prefers-reduced-motion）では歩き回らない

### 【仮】読み上げ機能

投稿・ノックの返事・会議の発言についている 🔊 ボタン、または**アイコンをクリック**すると、文章を声で読み上げます（もう一度押すと停止）。キャラ一覧や家の大きいアイコンは自己紹介、会議室の席のアイコンはその人の最新の発言を読みます。ブラウザ標準の Web Speech API を使っているため、声は OS に入っている日本語音声です。ヤマネコは低め、ウサギは高め・はやめ、フクロウはとても低く・ゆっくり、シバは元気に早口で読みます。設定は `shared/speech.js` にあります。将来はキャラ専用の音声に差し替える予定です。

エージェントの発言はルールベース（テンプレート＋キーワード）なので、API キーなしで動きます。

## API

| メソッド | パス | 説明 |
| --- | --- | --- |
| GET | `/api/posts` | タイムライン |
| POST | `/api/posts` | 投稿 `{authorId, text, replyTo?}` |
| POST | `/api/posts/:id/like` | いいねの切り替え `{userId}` |
| POST | `/api/users` | 名前で参加（同じ名前なら同じユーザー） `{name}` |
| GET | `/api/agents` / `/api/agents/:id` | エージェントの家の情報 |
| POST | `/api/agents/:id/knock` | 家をノックする |
| GET / POST | `/api/meetings` | 会議一覧／招集 `{topic, createdBy?}` |
| GET | `/api/meetings/:id` | 会議の詳細 |
| POST | `/api/meetings/:id/messages` | 人間が発言 `{authorId, text}` |
| POST | `/api/meetings/:id/step` | 会議を1手進める |
| GET | `/api/events` | 変更通知（Server-Sent Events） |
